1. PROJECT OVERVIEW & PURPOSE
================================================================================

Brick Factory is a modern, high-performance web application designed for the 
construction industry, civil engineers, building contractors, architects, and 
individual home builders. 

Traditional brick estimation involves complex manual calculations prone to human 
error, leading to material shortages or costly over-purchasing. Brick Factory 
solves this problem by providing:
1. Automated & Highly Accurate Estimation Engine: Computes exact brick counts, 
   mortar requirements, cement bags, sand volume (cft / m3), and total project cost.
2. Real-Time Interactive 3D Visualization: Uses WebGL / Three.js to render the 
   exact structure with custom wall dimensions, doors, windows, and ventilators.
3. Complete E-Commerce & Bulk Order Ecosystem: Browse brick varieties, check 
   specifications, place bulk inquiries, and calculate logistics seamlessly.
4. AI-Powered Visual Estimation: Upload architectural sketches or blueprints to 
   extract dimensions and generate instant material estimates.

5. MATHEMATICAL FORMULAS & CALCULATION ENGINE (src/lib/brickCalculator.ts)
================================================================================

1. Net Wall Volume Calculation:
   - Gross Wall Volume = Wall Length × Wall Height × Wall Thickness
   - Total Deductions = Sum of (Opening Width × Opening Height × Wall Thickness) for all doors/windows
   - Net Wall Volume = Gross Wall Volume - Total Deductions

2. Single Brick Volume:
   - Volume without Mortar = Length × Width × Height
   - Nominal Volume with Mortar = (Length + MortarThickness) × (Width + MortarThickness) × (Height + MortarThickness)

3. Number of Bricks Required:
   - Base Bricks = Net Wall Volume / Nominal Brick Volume
   - Total Bricks with Wastage = Base Bricks × (1 + WastagePercentage / 100)

4. Mortar Quantity & Material Breakdown:
   - Total Mortar Volume = Net Wall Volume - (Base Bricks × Single Brick Volume without Mortar)
   - Dry Mortar Volume = Wet Mortar Volume × 1.33 (33% conversion factor for dry volume)
   - For a Mortar Mix Ratio (e.g., 1:6 = Cement:Sand, Total Parts = 7):
       * Cement Volume = Dry Mortar Volume × (1 / 7)
       * Cement Bags Required = (Cement Volume in m3 × 1440 kg/m3) / 50 kg per bag
       * Sand Volume in m3 = Dry Mortar Volume × (6 / 7)
       * Sand Volume in cft = Sand Volume in m3 × 35.3147

5. Cost Estimation:
   - Total Cost = (Total Bricks × Price Per Brick) + (Cement Bags × Price Per Bag) + (Sand cft × Price Per cft) + Estimated Labor

7. STEP-BY-STEP SETUP & EXECUTION GUIDE
================================================================================

[Prerequisites]
- Node.js (v18.18+ or v20+ recommended)
- npm or yarn or pnpm
- PostgreSQL database instance (optional for local calculator preview, required for DB features)

[Installation Steps]
1. Navigate to the project root:
   cd "D:\Bricks - Copy\brick-factory"

2. Install all dependencies:
   npm install

3. Configure Environment Variables:
   Copy `.env.example` to `.env` and fill in:
   - DATABASE_URL="postgresql://user:password@localhost:5432/brick_factory"
   - SMTP_HOST="smtp.gmail.com"
   - SMTP_PORT=587
   - SMTP_USER="your-email@gmail.com"
   - SMTP_PASS="your-app-password"

4. Database Sync (if using database):
   npx prisma db push
   npx prisma generate

5. Run Development Server:
   npm run dev

6. Open in Browser:
   http://localhost:3000

7. Build for Production:
   npm run build
   npm run start
